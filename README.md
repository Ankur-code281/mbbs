# Study MBBS Abroad - Landing Page

## Overview
This project is a responsive landing page designed to provide information and facilitate applications for students interested in studying MBBS abroad. The page includes details about top countries, admission processes, and an application form for students to submit their interest.

## Features
- **Hero Section:** A visually appealing banner with a call-to-action (CTA) button.
- **Why Study MBBS Abroad Section:** Highlights the benefits of pursuing medical education overseas.
- **Top Countries Section:** Showcases popular destinations for MBBS studies.
- **Admission Process & Eligibility Section:** Breaks down the step-by-step admission process.
- **Application Form:** Allows users to submit their details to apply for MBBS abroad.
- **SEO Optimized:** Includes metadata for better search engine ranking.
- **Google Analytics & Facebook Pixel Integration:** Tracks visitor interactions for marketing and analytics purposes.

## Technologies Used
- **HTML5:** Structuring the webpage content.
- **CSS3 & Tailwind CSS:** Styling and responsive design.
- **JavaScript:** Form validation and event handling.
- **Google Analytics:** Tracks user activity on the page.
- **Facebook Pixel:** Helps in retargeting and analyzing ad performance.

## Setup & Usage
To use this landing page, follow these steps:

1. **Download or Clone the Repository**
   ```sh
   git clone https://github.com/your-repo/study-mbbs-abroad.git
   cd study-mbbs-abroad
   ```

2. **Open in a Browser**
   - You can directly open the `index.html` file in a browser.

3. **Modify Google Analytics & Facebook Pixel IDs**
   - Replace `GA_TRACKING_ID` in the script section with your Google Analytics ID.
   - Replace `FB_PIXEL_ID` with your Facebook Pixel ID.

4. **Customize Content**
   - Update the `hero-image.jpg` with a relevant banner image.
   - Modify text content and styling as needed in the HTML file.

## Application Form Submission
- The form currently points to `submit.php`. If using a backend, modify `action` to your API endpoint.
- JavaScript validation prevents submission of empty fields.
- Upon submission, an alert confirms success.
